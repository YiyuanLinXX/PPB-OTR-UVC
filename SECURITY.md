# Security policy

## Supported versions

Security and safety-related fixes are applied to the latest version on the default branch. No older release line is currently maintained.

## Reporting a vulnerability

Please use GitHub's **Security → Report a vulnerability** workflow for private reports. If private vulnerability reporting is unavailable, contact the maintainer at `yl3663@cornell.edu` with the subject `PPB-OTR-UVC security`.

Include the affected component, reproduction conditions, potential impact, and whether the issue could unexpectedly energize UV lamps or move the robot. Do not include live credentials, precise private-field coordinates, or personal data. Please allow a reasonable period for assessment before public disclosure.

Operational emergencies and suspected UV exposure require the site's emergency procedure; a GitHub report is not an emergency-response channel.

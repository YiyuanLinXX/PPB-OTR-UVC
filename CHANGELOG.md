# Changelog

All notable changes to this project will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.6.0] - 2026-08-27

### Added

- Initial public release of prescription-driven UV treatment control.
- Dual-antenna UM982 RTK-GNSS navigation and Farm-ng Amiga serial bridge.
- Dynamic treatment/transit speed coordination with acknowledgement gating.
- Lamp-off gates for GNSS validity, navigation activity, command ownership, speed acknowledgement, and shutdown.
- Persistent mission recovery and missed-boundary detection.
- Public documentation, test workflow, contribution guidance, and safety notes.
- Apache License 2.0 for the initial public release.
